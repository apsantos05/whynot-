## Regras rápidas
- DJs no tom claro (vídeo + capa), artes na base escura, alternando no feed.
- Valores nunca no Instagram, só no grupo do WhatsApp.
- Exportar sempre PNG HD (2160 px de largura).
- Mesmo estilo sempre; o tom de cor muda por edição. Simples, sem poluir, low light.
