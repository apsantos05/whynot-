## Sequência típica de uma edição
```
Save the date → Revelação dos DJs (Reels + arte de gatilho entre eles) → Line-up completo
→ Flyer com todos + anúncio → Lista abre (D-1) → É amanhã → Dia da festa (stories de hora em hora)
→ Pós-festa (fotos + caixinha "quem você quer na próxima?")
          ↘ se a venda estiver baixa em D-5 a D-3: Urgência (06)
```
